# Sweden Car

En liten 3D-webbläsarprototyp om Stig, Ullervad och en Volvo 945. Innan spelet startar får spelaren göra ett enkelt körkortstest med tre trafikfrågor.

## Starta

Öppna `index.html` via en lokal webbserver (exempelvis VS Code Live Server) eller publicera repot med GitHub Pages. Three.js hämtas från jsDelivr, så spelet behöver internetanslutning.

## Körkortstest

På startskärmen väljer du **Ta körkort**. Svara rätt på tre trafikfrågor för att låsa upp **Börja spelet**. Vid fel svar kan testet göras om.

## Kontroller

- **WASD** eller piltangenter: gå
- **Shift**: spring
- **E**: använd föremål/närliggande fordon
- Touchknappar finns på mobil

## Spelinnehåll

- Gå runt i en enkel 3D-miljö i Ullervad och Mariestad
- Jobba med vedleverans, bärgning och bilreparation
- Köp delar på Mekonomen, mat på Coop och bensin på OKQ8
- Bygg Volvo 945:ans motor; träffa Isabell, leta fälgar och hitta spöket på natten

Detta är en liten originalprototyp, inte ett fullskaligt 3D-spel.
